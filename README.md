# اوی‌استور — نسخه چندصفحه‌ای

این پروژه نسخهٔ تفکیک‌شدهٔ فروشگاه است: به‌جای یک فایل تک‌صفحه‌ای (SPA)، حالا هر بخش یک فایل/آدرس واقعی مثل سایت‌های بزرگ (دیجی‌کالا و مشابه) دارد، اما همه به **یک سبد خرید مشترک** وصل هستند (سبد در `localStorage` مرورگر ذخیره می‌شود، پس بین همهٔ صفحات و آدرس‌ها یکی است).

## ساختار فایل‌ها

```
index.html                 صفحه اصلی (بنر، معرفی، پیشنهاد تصادفی)
search.html                صفحه جستجوی محصولات
cart.html                  سبد خرید + فرم تکمیل سفارش/پرداخت
products/
  1/index.html              صفحه اختصاصی محصول با کد 1  → آدرس: /products/1/
  2/index.html               ...
  _template.html            قالبی که صفحات بالا از روی آن ساخته می‌شوند (دستی ویرایشش نکنید مگر بخواهید طرح صفحه محصول را عوض کنید)
assets/
  style.css                 استایل مشترک همهٔ صفحات
  common.js                 منطق مشترک: سبد خرید، فرمت قیمت، رندر کارت محصول، توست و ...
  products.json             دیتای محصولات (نمونه — جایگزین‌اش کنید یا از API خودتان serve کنید)
generate-products.js         اسکریپت Node که صفحات products/<code>/ را از روی products.json می‌سازد
```

## چطور محصول اضافه/ویرایش کنم؟

1. `assets/products.json` را ویرایش کنید (یک آبجکت جدید با `code` یکتا اضافه کنید).
2. در ترمینال بزنید:
   ```
   node generate-products.js
   ```
   این کار پوشهٔ `/products/<code>/index.html` را برای محصول جدید می‌سازد (برای سئو: تایتل، توضیحات و تصویر از قبل در HTML نوشته می‌شود).
3. توجه: قیمت و موجودی واقعی همیشه به‌صورت زنده از `products.json` توسط جاوااسکریپت خوانده می‌شود، پس حتی اگر صفحهٔ محصول را regenerate نکنید، قیمت نمایش داده‌شده تازه خواهد بود؛ فقط متادیتای سئو (title/description) وقتی خیلی عوض شود بهتر است regenerate شود.

## اتصال به سرور واقعی

- در `assets/common.js`، مقدار `CONFIG.PRODUCTS_URL` را به آدرس API واقعی محصولات خودتان تغییر دهید (اگر با `/assets/products.json` فرق دارد).
- در `cart.html`، فرم پرداخت به `POST /api/create-payment` وصل می‌شود (همان منطق نسخهٔ قبلی؛ `CONFIG.API_BASE` در `common.js` قابل تغییر است).

## چیزهایی که اضافه شد نسبت به نسخه اصلی

- هر محصول آدرس اختصاصی خودش را دارد (`/products/{code}/`) — قابل اشتراک‌گذاری، ایندکس در گوگل، و دکمهٔ برگشت مرورگر به‌درستی کار می‌کند (چون دیگر SPA نیست).
- تگ‌های `og:title` / `og:description` / `og:image` برای هر محصول تولید می‌شود (برای پیش‌نمایش بهتر در شبکه‌های اجتماعی).
- بخش "محصولات مشابه" در پایین صفحهٔ هر محصول اضافه شد.
- breadcrumb (خانه / محصولات / نام محصول) در صفحهٔ محصول اضافه شد.
- لینک "مشاهده محصولات" وقتی سبد خالی است اضافه شد.
- سبد خرید بین صفحات از طریق `localStorage` + یک ماژول مشترک (`common.js`) هماهنگ نگه داشته می‌شود، و شمارندهٔ سبد در هدر/ناوبری پایین در همهٔ صفحات هم‌زمان آپدیت می‌شود.

## اجرا روی هاست

چون این یک سایت کاملاً استاتیک (HTML/CSS/JS) است، کافیست کل پوشه را روی هر هاست استاتیک (مثل Cloudflare Pages، Netlify، Vercel یا هر هاست معمولی) آپلود کنید. فقط دقت کنید مسیر ریشهٔ سایت باید همین پوشه باشد تا آدرس‌های `/assets/...` و `/products/...` درست کار کنند.
